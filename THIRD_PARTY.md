## Colour data

`src/core/color/palettes_data.inc` is generated by `tools/gen_palettes.py` from these sources:

| Data | Source | License |
|---|---|---|
| CSS4 and Tableau colours, matplotlib colormaps (viridis, plasma, inferno, magma, cividis, turbo, twilight, ...) | matplotlib | Matplotlib license (BSD-style); viridis family CC0 |
| xkcd colour names | xkcd colour survey | CC0 |
| ColorBrewer palettes | Cynthia Brewer, via matplotlib | Apache-2.0 |
| cmocean colormaps | K. Thyng et al. | MIT |
| Scientific Colour Maps (batlow, roma, vik, ...) | F. Crameri, via cmcrameri | MIT |
| colorcet / CET perceptually uniform maps, Glasbey palettes | P. Kovesi; Holoviz colorcet | CC-BY 4.0 |
| X11 colour names | X.Org `rgb.txt` | MIT/X11 |
| Okabe–Ito, Paul Tol, IBM, Solarized, Nord, Dracula, Gruvbox palettes | published colour values | factual data |
| Grace default colours, fill patterns and file format | Grace | GPL-2.0-or-later |
