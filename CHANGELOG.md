# Changelog

## 0.9.0 — first public release

- Qt 6 application for Windows, macOS (native, universal) and Linux (X11 and Wayland)
- Grace compatibility:
  - reads and writes .agr projects, including xmgr-era files;
  - runs the Grace command language in projects, parameter and batch files and the console;
  - gracebat-compatible command line (`cactusbat`).
- Every Grace set type and graph type, all tick-label formats, the 32 Grace fill patterns, and rich
  text with Grace escapes and `$TeX$` math.
- Modern default style, 7 style presets, about 1800 named colours, 51 palettes and 158 colormaps.
- Curve fitting with live preview, regressions, FFT, histograms, interpolation, running statistics
  and other transformations.
- Exports to PDF, SVG, EPS/PS, PNG, JPEG, TIFF, BMP, PPM and WebP.
- Undo/redo, live inspector, data sheet, command console, drawing tools, regions, themes, autosave.
