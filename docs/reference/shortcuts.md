# Mouse and keyboard

On macOS, use **⌘** wherever **Ctrl** is written.

## Mouse

| Action | Effect |
|---|---|
| Wheel | Zoom the graph under the cursor, keeping the point under the cursor fixed |
| Shift + wheel | Zoom x only |
| Alt + wheel | Zoom y only |
| Ctrl + wheel | Zoom the page view (not the data) |
| Drag inside a graph (Select tool) | Pan |
| Middle-button drag | Pan, with any tool |
| Click | Select (graph, set, axis, legend, title, annotation) |
| Drag a legend, title or annotation | Move it |
| Double-click | Open the element's settings in the Appearance window |
| Right-click | Context menu |
| Drop files on the window | Open projects, import data |

## Tools

| Key | Tool |
|---|---|
| V | Select |
| H | Pan |
| Z | Zoom box |
| Shift+X, Shift+Y | Zoom x only, zoom y only |
| C | Crosshair |
| P | Edit points (drag; Ctrl+click deletes, Shift+click adds) |
| T, L, A, B, E | Text, line, arrow, box, ellipse |
| R | Region (click corners, double-click to finish) |
| Esc | Back to Select (and cancel a region) |

## Editing

| Key | Action |
|---|---|
| Ctrl+Z, Ctrl+Shift+Z (Ctrl+Y) | Undo, redo |
| Delete, Backspace | Delete the selected set or annotation |
| Arrow keys (Shift: bigger steps) | Nudge the selected legend or annotation |
| Ctrl+Shift+C | Copy the plot as image and SVG |
| Ctrl+Shift+V | Import data from the clipboard |

## Files

| Key | Action |
|---|---|
| Ctrl+N | New project |
| Ctrl+O | Open |
| Ctrl+S, Ctrl+Shift+S | Save, save as |
| Ctrl+I | Import data |
| Ctrl+E | Export |
| Ctrl+Shift+E | Export again with the same settings |
| Ctrl+P | Print |
| Ctrl+Q | Quit |

## Windows and tools

| Key | Action |
|---|---|
| Ctrl+Shift+P | Appearance window |
| Ctrl+D | Set editor (spreadsheet) |
| Ctrl+K | Commands window |
| Ctrl+R | Evaluate expression / new set |
| Ctrl+T | Transformations |
| Ctrl+F | Curve fitting |
| Ctrl+, (KDE: Ctrl+Shift+,) | Preferences |

## View and plot

| Key | Action |
|---|---|
| Ctrl+Shift+A | Autoscale the current graph |
| Ctrl+G | Toggle grid lines |
| Ctrl+L | Toggle the legend |
| Ctrl++, Ctrl+− | Zoom the page view in and out |
| Ctrl+0 | Fit the page in the window |
| F1 | Open this documentation |
